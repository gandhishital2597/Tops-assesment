SCENARIO 1
You are a junior developer at a fintech startup building a digital wallet app. The team is
debating between Waterfall and Agile methodology. The project has frequently
changing requirements and the client expects to review working features every two
weeks.

Question: context.
Which development methodology would you recommend for this project, and why?
Identify two specific risks the team would face if they chose the wrong methodology for this
Answer:
Q1: Waterfall vs Agile

Answer:

I would recommend using Agile methodology for this project.

Reason:

The project has frequently changing requirements
The client wants working features every two weeks

Agile supports:

Iterative development (small parts delivered regularly)
Continuous feedback from clients
Flexibility to adapt changes quickly

Risks if wrong methodology (Waterfall) is used:

Late feedback risk: Client will only see final product → changes become costly
Requirement mismatch risk: Final product may not meet updated requirements


Q2: Git Workflow

Answer:

The team should adopt a feature branch workflow.

Workflow:

Each developer works on a separate branch
Code is reviewed before merging into main branch

Git Commands:

git branch feature-name
→ Creates a new branch for development
git checkout feature-name
→ Switch to that branch
git merge feature-name
→ Merge code into main after testing
git pull
→ Get latest updates from repository

Benefit:

Prevents breaking the main branch
Ensures stable code for demo

🔹 Q4: Bootstrap Grid System

Answer:

Bootstrap uses a 12-column grid system.

Class Example:

<div class="col-12 col-md-4"></div>

Explanation:

col-12 → Full width on mobile (1 column)
col-md-4 → 3 columns on medium+ screens (12/4 = 3 columns)

Result:

Mobile → 1 column
Desktop → 3 columns
🔹 Q5: Array for Rainfall Data

Answer:

Why array is better:

Stores multiple values in one variable
Easy to loop and process data
Avoids writing 30 separate variables

Logic:

Step 1: Calculate average

Loop through array
Sum all values
Divide by 30

Step 2: Find above-average days

Loop again
Compare each value with average

Why not in single loop:

Average must be known first
You cannot compare without calculating it

#include <stdio.h>

int main() {
    float hours[7], total = 0, avg;
    int i, maxDay = 0;

    for (i = 0; i < 7; i++) {
        do {
            printf("Enter study hours for Day %d: ", i + 1);
            scanf("%f", &hours[i]);
        } while (hours[i] < 0 || hours[i] > 24);

        total += hours[i];

        if (hours[i] > hours[maxDay])
            maxDay = i;
    }

    avg = total / 7;

    printf("\nTotal = %.2f\nAverage = %.2f\n", total, avg);
    printf("Highest study day: Day %d\n\n", maxDay + 1);

    // Bar Chart
    for (i = 0; i < 7; i++) {
        printf("Day %d: ", i + 1);
        for (int j = 0; j < (int)hours[i]; j++)
            printf("*");
        printf("\n");
    }

    return 0;
}

#include <stdio.h>

struct Student {
    char name[50];
    int rollno;
    float marks;
    char grade;
};

void assignGrade(struct Student *s) {
    if (s->marks >= 90)
        s->grade = 'A';
    else if (s->marks >= 75)
        s->grade = 'B';
    else if (s->marks >= 60)
        s->grade = 'C';
    else if (s->marks >= 45)
        s->grade = 'D';
    else
        s->grade = 'F';
}

void printTopper(struct Student s[], int n) {
    int i, top = 0;

    for (i = 1; i < n; i++) {
        if (s[i].marks > s[top].marks)
            top = i;
    }

    printf("\nTopper: %s (%.2f marks)\n", s[top].name, s[top].marks);
}

int main() {
    struct Student s[3];
    int i;

    for (i = 0; i < 3; i++) {
        printf("\nEnter details for student %d\n", i + 1);
        printf("Name: ");
        scanf("%s", s[i].name);
        printf("Roll No: ");
        scanf("%d", &s[i].rollno);
        printf("Marks: ");
        scanf("%f", &s[i].marks);

        assignGrade(&s[i]);
    }

    printf("\n--- Student Records ---\n");
    printf("Name\tRoll\tMarks\tGrade\n");

    for (i = 0; i < 3; i++) {
        printf("%s\t%d\t%.2f\t%c\n",
               s[i].name, s[i].rollno, s[i].marks, s[i].grade);
    }

    printTopper(s, 3);

    return 0;
}

Section C — Mini Project: Student Productivity Tracker (C Program)

Mini Project: Student Productivity Tracker
Objective:
Build a console-based Student Productivity Tracker that logs daily study hours across subjects
for a full week, combining arrays, structures, functions, and file handling from Module 3 into a
single working program.
Your project must:
The program must be menu-driven with at least 3 options: (1) Log Today's Study Hours, (2)
View Weekly Report, (3) Save & Exit.
Define a struct StudyLog { char subject[40]; float hours[7]; } and create an array of at least 3
subject records.
Write a function that calculates and displays the weekly total hours and daily average for
each subject.
Display a simple text-based progress chart: for each subject, print one filled dot (•) per hour
studied that day (truncate to nearest integer).
On exit, save all records to a file named productivity_log.txt using fprintf(), with each subject's
name and 7 daily values written as a single comma-separated line.

Answer:


#include <stdio.h>
#include <string.h>

#define SUBJECTS 3
#define DAYS 7

struct StudyLog {
    char subject[40];
    float hours[DAYS];
};

void logStudy(struct StudyLog s[]) {
    int i, day;

    printf("\nEnter day number (1-7): ");
    scanf("%d", &day);

    if (day < 1 || day > 7) {
        printf("Invalid day!\n");
        return;
    }

    for (i = 0; i < SUBJECTS; i++) {
        printf("Enter hours for %s: ", s[i].subject);
        scanf("%f", &s[i].hours[day - 1]);
    }

    printf("Study hours logged successfully!\n");
}

void weeklyReport(struct StudyLog s[]) {
    int i, j;
    float total, avg;

    printf("\n--- Weekly Report ---\n");

    for (i = 0; i < SUBJECTS; i++) {
        total = 0;

        for (j = 0; j < DAYS; j++) {
            total += s[i].hours[j];
        }

        avg = total / DAYS;

        printf("\nSubject: %s\n", s[i].subject);
        printf("Total Hours: %.2f\n", total);
        printf("Daily Average: %.2f\n", avg);

        // Progress Chart
        printf("Progress:\n");
        for (j = 0; j < DAYS; j++) {
            printf("Day %d: ", j + 1);
            for (int k = 0; k < (int)s[i].hours[j]; k++) {
                printf("•");
            }
            printf("\n");
        }
    }
}

void saveToFile(struct StudyLog s[]) {
    FILE *fp = fopen("productivity_log.txt", "w");
    int i, j;

    if (fp == NULL) {
        printf("Error opening file!\n");
        return;
    }

    for (i = 0; i < SUBJECTS; i++) {
        fprintf(fp, "%s", s[i].subject);

        for (j = 0; j < DAYS; j++) {
            fprintf(fp, ",%.2f", s[i].hours[j]);
        }

        fprintf(fp, "\n");
    }

    fclose(fp);
    printf("Data saved to file successfully!\n");
}

int main() {
    struct StudyLog subjects[SUBJECTS] = {
        {"Math", {0}},
        {"Science", {0}},
        {"Programming", {0}}
    };

    int choice;

    while (1) {
        printf("\n==== Student Productivity Tracker ====\n");
        printf("1. Log Today's Study Hours\n");
        printf("2. View Weekly Report\n");
        printf("3. Save & Exit\n");
        printf("Enter your choice: ");
        scanf("%d", &choice);

        switch (choice) {
            case 1:
                logStudy(subjects);
                break;

            case 2:
                weeklyReport(subjects);
                break;

            case 3:
                saveToFile(subjects);
                printf("Exiting program...\n");
                return 0;

            default:
                printf("Invalid choice! Try again.\n");
        }
    }

    return 0;
}

D Section D — AI-Augmented Learning

STEP 1 · BUILD WITH AI
Use an AI tool of your choice (ChatGPT, Claude, GitHub Copilot, etc.) to help you write a C program
that:
Accepts exactly 10 integers from the user using a loop and stores them in an array.
Finds and displays the maximum value, minimum value, and arithmetic mean (displayed as a
float with 2 decimal places).
Sorts the array in ascending order using any sorting method and displays the sorted list.
Prints whether the mean is closer to the minimum, closer to the maximum, or exactly midway
between them.
STEP 2 · TEST & DEBUG (WITHOUT AI)
Then, working without AI, test the code using boundary inputs: (a) all 10 values identical, (b) a
mix of positive and negative integers, and (c) a list where the mean falls exactly between min
and max. Find at least one bug, edge-case failure, or improvement in the AI's solution and fix it
yourself.


#include <stdio.h>

int main() {
    int arr[10], i, j, temp;
    int max, min;
    float sum = 0, mean;

    printf("Enter 10 integers:\n");
    for (i = 0; i < 10; i++) {
        scanf("%d", &arr[i]);
        sum += arr[i];
    }

    max = min = arr[0];

    for (i = 1; i < 10; i++) {
        if (arr[i] > max) max = arr[i];
        if (arr[i] < min) min = arr[i];
    }

    mean = sum / 10;

    // Sorting (Bubble Sort)
    for (i = 0; i < 9; i++) {
        for (j = 0; j < 9 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }

    printf("\nMin = %d\nMax = %d\nMean = %.2f\n", min, max, mean);

    printf("Sorted array: ");
    for (i = 0; i < 10; i++)
        printf("%d ", arr[i]);

    printf("\n");

    // Check closeness
    float mid = (min + max) / 2.0;

    if (mean == mid)
        printf("Mean is exactly midway.\n");
    else if (mean < mid)
        printf("Mean is closer to minimum.\n");
    else
        printf("Mean is closer to maximum.\n");

    return 0;
}
